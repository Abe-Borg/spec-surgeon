# Spec Surgeon v0.4.1

Fixes from the hands-on sweep of v0.4.0: a changed template requires a new preview, mixed template batches
handle single-section specs, and read-only files are set aside without stopping the rest of the batch.

## Installing

- **From v0.4.0:** choose **Help → Check for updates…**, then **Install now**. The app checks the installer,
  closes, installs the update and reopens.
- **New installation or v0.3.x:** download `SpecSurgeon-0.4.1-Setup-x64.exe` from this release and run it.
  No administrator rights are needed. Existing settings and results are kept.
- **Python:** install `spec_surgeon-0.4.1-py3-none-any.whl` from this release; add `[gui]` for the window.

## Fixes

- **Preview approval covers the template.** Editing or replacing a template spec after Preview now prevents
  Run until a new preview is approved, even when the template's timestamp has been restored. This applies to
  the window and commands that use an approval token.
- **Conflicting operations are caught during planning.** Removing headers/footers while a font or paragraph
  operation still includes those parts now produces a conflict with a hint to narrow its scope, rather than
  failing verification for every file after applying the edit.
- **Single-section specs work with cover/body templates.** A batch can contain both single-section and
  multi-section specs without rejecting valid fill rules for template sections a particular file does not use.
  Rules naming a slot absent from every mapped template section are still refused.
- **Read-only files stay untouched.** Guarded write-back refuses read-only sources and reports failed file
  replacements as verification failures, removes temporary files and continues with the other files.
- **Tracked deletions are clear in Preview.** A deletion-only edit now says how many blocks receive a tracked
  deletion and explains that the words remain visible as redlines until accepted.
- Simplified an equivalent false return in the formatting selector; behavior is unchanged.
