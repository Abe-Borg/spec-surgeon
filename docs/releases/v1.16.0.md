# Spec Surgeon 1.16.0

Changes since v1.15.0.

## Edit and extend saved recipes

- **Manage → Edit** changes a saved recipe's name, description and steps: move steps up or down, remove them, or change a Safe-mode button's saved form where its fields do not read attached files.
- **Save as a recipe → Add to a saved recipe** adds the selected changes after its existing steps. The dialog and chat explain when adding a request changes the recipe's mode.
- An edit refuses to overwrite a recipe changed in another window. A run form opened before the recipe's steps changed must be reopened before it can run.

## Clearer reasons and a tidier window

- **Left untouched** names the recipe step that could not cover a document, what it looked for and what it found instead, including missing words, section numbers and template settings.
- **Remove all documents** stays beside the documents title when the list folds away.
- **New conversation** clears the previous failure and any open recipe run form.
- A preview without a layout reference says so in one sentence.
- A new scalpel and tracked-change icon identifies the app in the window, browser tab and Windows installer.

## The guided tour, brought up to date

The tour now matches the window as it is today.

- Every step was checked against the real window. The words that had fallen behind are fixed: the folder button
  opens the window's scratch folder, where copies wait until **Export** saves them (a saved copy is marked SAVED, and
  CHANGED if you edit it in Word afterwards); **New conversation** no longer archives anything; **Tour** in the top
  bar starts the tour again; **Create** counts the copies it makes; Safe mode's buttons are described in their five
  groups; a preview card's page-layout line and the **Worth knowing** notes are explained.
- Two new steps: a question that gets only an answer ends the request (and a request that names some documents keeps
  to those), and what the preview of a custom method lists before you approve it.
- The find-and-replace chapter shows the **Find and replace** form it ran, with its pair, instead of the template
  button's form.
- The tour always opens Safe mode on its buttons, even when you had a button's form open, and when it ends your own
  form comes back as it was, with what you had typed. The tour's form and values no longer stay behind in your panel.
- The tour's practice copies are kept in the window's own scratch folder and deleted when the tour ends. Two windows
  each running a tour no longer share, or delete, each other's practice copies.
- If you finished the earlier tour, the chip at the top of an empty conversation invites you to take it once more.

## Installing and updating

- Existing installations: use the update banner or **About → Check for updates**.
- Windows: download `SpecSurgeon-1.16.0-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.16.0-py3-none-any.whl`; add `[gui]` for the window and `[agent]` for typed requests.
- `SHA256SUMS` covers the installer, Python distributions and bundled dependencies' source archives.
