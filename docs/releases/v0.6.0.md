# Spec Surgeon v0.6.0

Run saved changes without an API key, apply independently verified formatting properties, and reuse
your library from a conversation with Claude. This release includes all progress merged since v0.5.0,
including the Qt window teardown crash fix.

## Installing and updating

- **From v0.4.x or v0.5.0:** choose **Help → Check for updates…**, then **Install now**. The app verifies
  the installer, closes, installs the update and reopens. Existing settings, library items and results
  are kept.
- **New installation or v0.3.x:** download `SpecSurgeon-0.6.0-Setup-x64.exe` from this release and run it.
  No administrator rights are needed.
- **Python:** install `spec_surgeon-0.6.0-py3-none-any.whl` from this release; add `[gui]` for the window
  and `[agent]` for Claude. Saved specs and library items run without an API key.

## Running without an API key

- The window switches to **Choose the change**, putting saved specs and **Your library** first.
  Preview, Run, independent verification, set-aside passes and diagnostics remain available.
- The window explains which features need a key: plain-English requests, new custom transforms,
  Claude's visual review and advice on set-aside files. Adding a key in Settings restores those
  features and any draft request, including advice after a keyless run.
- `spec-surgeon library use NAME FILES…` previews and runs a saved recipe or operation without a key.
  Saved operations must pass trials on the current files first and deliver edited copies only.
  Preview approval and changed-input checks still apply.
- Without a key, Claude's visual review is recorded as skipped; it sends nothing and does not block
  Run. The independent V1–V10 checks still decide whether each file passes.

## Verified formatting properties

- The new `set_properties` operation sets **bold, italic, caps, small caps, strikethrough, underline
  and text colour**, plus **keep with next, keep lines together, widow control and page break before**.
  It can target document text or named style definitions. Caps changes how letters display and adds
  no characters.
- Properties already showing the requested value remain untouched. Targeted direct changes can be
  tracked; style-definition changes are untracked. Bold and italic include Word's complex-script twins.
- Independent V10 verification checks the effective result, predicted target counts and unrelated
  formatting. Conflicting caps/small-caps settings and ambiguous style changes are refused.
- `examples/specs/bold-part-headings.json` is a worked example. Profiles also report italic and theme
  colour information so the compiler can understand existing formatting.

## Claude and your library

- During a conversation, Claude can list and inspect saved library items and offer a matching recipe
  or operation. The choice shows the saved item's exact words for approval; choosing it uses that item
  as saved. Recipes are dry-planned on the current batch, and operations are tried before use.
- Each offer is pinned to the item's hash. A changed item requires a new offer, and library reads
  refuse paths that lead outside the library. A saved operation that fails its trials returns to the
  conversation so you can choose another approach.

## Qt stability

- Window teardown waits for background jobs and deletes windows and their owned Qt objects on the GUI
  thread. This fixes a segmentation fault caused by later garbage collection on a worker thread.
  Objects still in use are kept alive if teardown times out. Regression checks exercise this lifetime
  across process and thread boundaries.

## Validation and remaining limits

The release workflow gates publication on the full Linux suite with Qt and LibreOffice, package metadata
and clean-wheel installation checks, Windows tests, and the installed Windows app's preview, run and
update checks. Tests use scripted Claude responses and isolated settings; they do not call the live API
or touch your saved API key. Live Claude behavior, real-project sweeps and Word COM rendering still need
validation on the target machine. The installer, wheel and source archive are listed in `SHA256SUMS`.
