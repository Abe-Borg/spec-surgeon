# Spec Surgeon 1.3.0

Includes all changes merged since v1.2.1, including PR #43. The desktop now opens
one conversation: attach Word documents, optionally attach a reference template,
describe the result, review the preview and create verified copies.

## Installing and updating

- Existing installations: choose **Help → Check for updates…**, then **Install now**.
- Windows: download `SpecSurgeon-1.3.0-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.3.0-py3-none-any.whl`; add `[gui]` for the window
  and `[agent]` for typed requests. Checksums are in `SHA256SUMS`.

## Changes

- The default desktop combines explicit DOCX attachments, an optional template,
  chat, readable proposed changes and before/after pages. Only attached files
  enter the conversation; dropping a file does not select its neighbors.
- Questions and wording decisions stay in the conversation. Ordinary edits use
  one preview approval and the existing independent engine verification.
  Originals are preserved, and each result uses a separate output folder.
- The window shows page-count changes, elapsed time, estimated spending and
  cancellation. Saved conversations retain decisions, result links, resource
  accounting and recovery checkpoints; reopening requires fresh execution approval.
- A shared initial allowance covers conversation, custom preparation, visual
  review and recovery. Explicit budget extensions resume paused work, and
  successive partial recovery exports preserve earlier copies, including after
  reopening the conversation.
- The previous desktop remains an internal integration test harness. CLI
  commands and deterministic offline editing remain available.
- Release publication checks handle annotated tags when checking that source
  distributions and the Windows installer match the tagged commit.

See the [conversational desktop guide](https://github.com/Abe-Borg/spec-surgeon/blob/v1.3.0/docs/CONVERSATIONAL_DESKTOP.md)
for persistence, resource limits and preview behavior.

## Validation and remaining acceptance

Publication is gated by the existing Linux and Windows test suites, Qt and
LibreOffice checks, distribution validation, clean wheel installation and
installed Windows app/update checks.

Automated tests use generated DOCX fixtures and scripted model responses. The
private 12-specification corpus is unavailable in this checkout; its replay tests
skip explicitly. Owner-machine Word replay, human visual acceptance and a live
model request measuring elapsed time and cost remain pending. This release does
not claim those acceptance results.
