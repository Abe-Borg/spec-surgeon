# Spec Surgeon 1.10.0

Includes the changes merged in PRs #90–93 since v1.9.0.

## Faster responses and batches

- **Optional fast responses.** Settings → Fast responses offers Claude's fast mode, off by default. Turning it on
  requires a second click that names the price: twice the standard token prices, with up to 2.5× faster output.
  It uses the same model, effort and prompts. Usage and budgets account for the fast prices. When fast capacity is
  unavailable, the call retries at standard speed; Settings and the status indicator reflect availability.
- **Files run side by side.** Batches of three or more documents now edit and independently verify separate files
  in worker processes, including in the installed Windows app. Larger previews plan files side by side and check
  multiple samples in parallel. Word rendering can share files among up to three private Word instances. Each
  document keeps the same planning, verification and delivery checks.

## Keeping the preview and choosing its files

- **One refused document keeps the others' preview.** A document the plan cannot handle stays under Left untouched
  with its reason while the other documents remain ready to review. It is never run when you create the approved
  copies and is never sent to recovery afterward. Investigation begins when no document can be planned or a sample
  fails its check. Setting aside every previewed document still begins the pass over those documents correctly.
- **Leave documents out of a request.** Ask to leave named documents unchanged. They are excluded from planning,
  previews and copies, including when the request falls back to a custom method, and are listed with the reason.
  The next request can include them again.
- **Each document can use its own approved wording.** A batch request can supply a different title or other template
  fill for each document in one plan. Those words are traced to the request, pinned to that source document and
  checked independently, so one document's wording cannot silently become another's.

## Fixes

- **Closing the window ends the app.** Once the app has closed its jobs and saved settings and logs, it exits without
  waiting for idle WebView2 or library threads. A closed window no longer leaves a process holding up an update.
- **Fast means fast is available.** The status indicator stops saying Fast when the provider has disabled fast mode
  for the session; Settings explains when standard speed is in use.

the exact PyMuPDF and MuPDF source archives alongside the installer, with their hashes in `SHA256SUMS`.

## Installing and updating

- Existing installations: use the update banner or **About → Check for updates**.
- Windows: download `SpecSurgeon-1.10.0-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.10.0-py3-none-any.whl`; add `[gui]` for the window and `[agent]` for typed requests.
- `SHA256SUMS` covers the installer, Python distributions and bundled dependencies' source archives.
