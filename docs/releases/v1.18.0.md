# Spec Surgeon 1.18.0

Changes since v1.17.0.

## Canadian numbering in Safe mode

- **Fonts & formatting → Convert to Canadian CSC PageFormat** uses the bundled Canadian scheme without an API key or an attached template.
- Choose **Automatic Word numbering** or **CSI numbers typed as text**, then preview and approve the copies. Automatic numbering keeps paragraph styles; typed CSI numbers take the Canadian scheme's styles.
- Numbers keep their values. Documents with a mixed, missing or ambiguous outline, or whose conversion cannot pass the checks, are left untouched with a reason.
- This converts numbering; use the template formatting buttons for page layout, fonts, headers and footers.

## Licenses and source

Spec Surgeon's own code remains under the MIT License. The Windows app bundles PyMuPDF and MuPDF and is distributed as a whole under the GNU AGPL v3. The installer and **About → Licenses** show both licenses. The release includes the corresponding PyMuPDF and MuPDF source archives.

## Installing and updating

- Existing installations: use the update banner or **About → Check for updates**.
- Windows: download `SpecSurgeon-1.18.0-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.18.0-py3-none-any.whl`; add `[gui]` for the window and `[agent]` for typed requests.
- `SHA256SUMS` covers the installer, Python distributions and bundled dependencies' source archives.
