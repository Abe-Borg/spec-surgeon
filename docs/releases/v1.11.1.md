# Spec Surgeon 1.11.1

This patch includes the fixes merged in PRs #105–108 since v1.11.0.

## Fixes

- Preview approval and filename verification now reflect the actual reviewed documents, and Safe mode no longer shows stale results.
- Drafts are kept separately for each mode, and starting a new conversation resets its input state.
- Settings reports whether a credential is available and lets you remove the app's saved key. Cached credentials are cleared when the key changes.
- Refused documents and failed preview checks now explain what happened so you can decide what to do next.

## Licenses and source

Spec Surgeon's own code remains under the MIT License. The Windows app bundles PyMuPDF and MuPDF and is distributed as a whole under the GNU AGPL v3. The installer and **About → Licenses** show both licenses. The release includes the corresponding PyMuPDF and MuPDF source archives.

## Installing and updating

- Existing installations: use the update banner or **About → Check for updates**.
- Windows: download `SpecSurgeon-1.11.1-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.11.1-py3-none-any.whl`; add `[gui]` for the window and `[agent]` for typed requests.
- `SHA256SUMS` covers the installer, Python distributions and bundled dependencies' source archives.

## Validation and remaining acceptance

Publication is gated by the release workflow's frontend tests and reproducible page build, Linux and Windows test suites, distribution checks, clean installed-wheel smoke test and installed Windows app validation.
