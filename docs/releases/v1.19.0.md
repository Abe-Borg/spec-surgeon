# Spec Surgeon 1.19.0

Changes since v1.18.0.

## Obliterate repair tools

- **Obliterate this one** takes a document from the to-do list into Obliterate with the request it was set aside from and its failure details.
- Custom methods can change a copy without predicting its changes first. The independent reader reports the words added and removed, formatting and structure changes, and file checks before approval. Create delivers the exact copies shown, marked **UNPROVEN**, or **UNVERIFIED** when a file check failed; a changed or missing preview copy requires a new preview.
- Raw XML edits can clear an obstacle before the original plan runs. The independent checker repeats the specified edit and compares the whole part exactly, while the preview lists changed words and other text outside paragraphs.
- Optional **hands-on tools** add a read-only part browser, search, **Save this part** and **Replace this part**. Replacement uses your file's exact bytes, a preview and independent checks, without AI.
- **Word actions** offers a fixed menu, including repair, removing protection, accepting or rejecting tracked changes, updating or unlinking fields, converting numbers to text, leaving compatibility mode, converting text boxes and deleting drawn shapes. Word makes a private copy first; its changes are shown before approval and the delivered copy is marked **UNPROVEN**. These actions require Microsoft Word and can run without an API key.
- The reader of Word-saved copies compares references by their destinations and reads complete style and numbering definitions, including document defaults.

## Rescue and export

- In Obliterate, **Try to rescue** attempts to attach a refused document, including legacy `.doc`, macro-enabled `.docm`, Strict Open XML and password-protected files where Word is available. The original stays untouched. A rescued document and its later copies keep the **SALVAGED** mark; a password is used only for that attempt, and the rescued copy has no password.
- Stop is checked between rescue steps and before replacing the attachment, so a stopped rescue attaches nothing.
- After a checked clean export leaves a marked copy without a file, Obliterate offers **Export anyway** using Word. The resulting clean Word file or PDF is named **UNCHECKED** and is never described as verified.
- Documents that share a file name each get their own Word-made file, PDF and record.

## Conversation and reliability

- A written reply to the outcome planner returns to the assistant. A composed plan's preview states its summary once.
- A completed job releases its busy state before sending its last frame, avoiding a spurious busy response immediately afterward.
- Outline and visual-check prompts explicitly treat document text as data. The chat's first message places the documents before the user's request.
- The Anthropic SDK is constrained to major version 2, and About names its Apache-2.0 license and the MIT terms for earlier contributions.

## Installing and updating

- Existing installations: use the update banner or **About → Check for updates**.
- Windows: download `SpecSurgeon-1.19.0-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.19.0-py3-none-any.whl`; add `[gui]` for the window and `[agent]` for typed requests.
- `SHA256SUMS` covers the installer, Python distributions and bundled dependencies' source archives.

## Validation and remaining acceptance

Publication is gated by the release workflow's frontend tests and reproducible page build, Linux and Windows test suites, distribution checks, clean installed-wheel smoke test and installed Windows app validation.

The owner's private 12-spec corpus replays, installed Windows candidate with Word, and live request in the installed candidate remain pending. The new Word actions, rescue and Word-made export paths also await real-file acceptance with Microsoft Word; automated tests use a stand-in for Word. Open findings and acceptance work are tracked in `docs/TRUST_CLAIMS.md` and `docs/BACKLOG.md`.
