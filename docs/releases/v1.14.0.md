# Spec Surgeon 1.14.0

Changes since v1.13.0.

## Twelve more Safe mode buttons

Safe mode adds **Change font**, **Page size and margins**, **Change the issue stamp**, **Add END OF SECTION where missing**, **Keep numbers with their units**, **Clean up spaces**, **Standardize quotes and dashes**, **Remove hyperlinks**, **Freeze fields as plain text**, **Remove unused styles**, **Set author and company**, and **Set proofing language**.

- Each button builds its plan from the form without an AI call, using the engine's existing operations and the same preview, approval and independent checks.
- **Accept all tracked changes** becomes **Accept or reject tracked changes**, with both choices in its form.
- **Change font** works without a template; a chosen size is planned against each document's own body size.
- **Page size and margins** lets the four margins share a row. When a paper size is chosen, a document with landscape pages is left untouched with the reason.
- **Change the issue stamp** accepts a list of one-line wordings.
- **Add END OF SECTION where missing** requires its wording to start with END OF SECTION, so pressing the button again on a finished copy adds nothing.

## A note explaining Safe mode

A note above the buttons explains what Safe mode can do and points to Default mode for requests beyond those buttons. **Add a Claude API key** opens Settings; **Switch to Default mode** changes the mode. **Hide** folds the note to one line, and that choice is saved. Help and the guided tour describe the new controls.

## Template placeholders filled from each document

**Match headers and footers to template** recognizes section-number placeholders such as `00 00 00`, `000000` and `## ## ##`, as well as more names for the section number and title, including `SECTION NO.`, `SPEC NUMBER`, `SECTION NAME`, `SPEC TITLE` and `Specification Name`. Brackets around a placeholder are accepted too.

The form identifies the placeholders each document fills from its own number and title and asks only for the remaining values. Previously, a template with `00 00 00` and `Specification Name` could ask for those as shared values and leave the placeholder wording in every copy.

## Installing and updating

- Existing installations: use the update banner or **About → Check for updates**.
- Windows: download `SpecSurgeon-1.14.0-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.14.0-py3-none-any.whl`; add `[gui]` for the window and `[agent]` for typed requests.
- `SHA256SUMS` covers the installer, Python distributions and bundled dependencies' source archives.
