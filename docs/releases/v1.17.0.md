# Spec Surgeon 1.17.0

Changes since v1.16.0.

## Format specifications

- The Specification Formatter can read a document's outline and work on chosen paragraphs. It can convert numbering between the bundled CSC PageFormat and CSI schemes, convert typed CSI numbers, and change numbering while keeping paragraph styles.
- Header and footer templates can carry the even/odd page setting when requested. The bundled schemes and worked examples are included with the app.
- Safe mode's **Remove specifier notes** removes notes identified by their own names.

## Stop and recover work

- Safe mode now has a **Stop** control that stops the work itself, including before a clean export writes files.
- Recovered runs retain their undo point and recipe step. Actions that would discard a recovery are held while its copies are waiting.
- Removing a document also removes its copy from the live results.

## Licenses and source

Spec Surgeon's own code remains under the MIT License. The Windows app bundles PyMuPDF and MuPDF and is distributed as a whole under the GNU AGPL v3. The installer and **About → Licenses** show both licenses. The release includes the corresponding PyMuPDF and MuPDF source archives.

## Installing and updating

- Existing installations: use the update banner or **About → Check for updates**.
- Windows: download `SpecSurgeon-1.17.0-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.17.0-py3-none-any.whl`; add `[gui]` for the window and `[agent]` for typed requests.
- `SHA256SUMS` covers the installer, Python distributions and bundled dependencies' source archives.
