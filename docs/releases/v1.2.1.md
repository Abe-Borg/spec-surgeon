# Spec Surgeon 1.2.1

Includes all changes merged since v1.2.0, including PRs #41 and #42.

## Installing and updating

- Existing installations: choose **Help → Check for updates…**, then **Install now**.
- Windows: download `SpecSurgeon-1.2.1-Setup-x64.exe` from this release and run it.
- Python: install `spec_surgeon-1.2.1-py3-none-any.whl`; add `[gui]` for the window
  and `[agent]` for typed requests. Checksums are in `SHA256SUMS`.

## Changes

- Ordinary edits now use one preview approval and independent engine verification.
  The separate outcome planner no longer blocks ordinary CLI, desktop, batch or
  chain delivery. Explicit office profiles and governed recovery retain their
  own review requirements.
- Runs default to persistent local application data, with warnings for synced or
  deep output folders. Shorter artifact paths, a Windows long-path manifest,
  thread workers by default and per-worker schema caches address live-run failures.
- Template fills clear placeholder-only color, highlight and shading by default;
  `slot_formatting: keep` preserves them when requested. Per-file literal bindings
  retain source identity, can be edited in preview and require a new preview.
- Whole-document font operations can update used list-label fonts while preserving
  symbol and picture labels. Font shorthand covers ascii/hAnsi/cs; eastAsia is
  explicit. The shipped Arial recipe retains its explicit list-font opt-out.
- Selectors and template fills support case-insensitive and flexible whitespace
  matching. Shipped section-number recipes handle spaced, hyphenated, compact and
  fourth-level numbers while preserving the captured source characters.
- Rendered preview samples show before/after page counts and flag page growth.
  Human records and reports group repeated findings and cap their size; complete
  machine evidence stays available separately. Copied results and diagnostic
  bundles retain the operation catalogs needed to read their histories.
- Compact operation indexes and on-demand operation descriptions reduce repeated
  context. The window exposes progress, elapsed time, calls, cost and cooperative
  cancellation, with clearer unavailable states and actionable errors.
- The README and contributor instructions are shorter; previous versions remain
  in `docs/history`.

## Validation and remaining acceptance

Publication is gated by the existing Linux and Windows test suites, distribution
checks, clean wheel installation and installed Windows app/update checks.

The private 12-specification corpus is not in this checkout, so its replay tests
skip explicitly. Owner-machine Windows/Word replay, visual acceptance and a live
model request measuring elapsed time and cost remain pending. No live-run
diagnostics bundle or private-corpus acceptance is claimed by this release.
