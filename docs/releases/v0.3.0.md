# Spec Surgeon v0.3.0

The first packaged release of Spec Surgeon includes the desktop window, deterministic Word specification editing, and the mixed-batch workflow for processing clean files while setting aside files that need another pass.

## Included

- Preview and run edits from the desktop window or CLI, with independent V1–V10 verification and guarded in-place delivery.
- Header/footer templating, font and paragraph formatting, page numbering, tracked text replacement, and tracked or untracked paragraph insertion and deletion.
- Body-aware fingerprints and profiles that distinguish messy, fragmented, and unstyled documents from clean templates.
- Flexible whitespace matching, formatting-noise handling, and fallback rules for extracting template fills.
- Set-aside manifests and reports, `spec-surgeon retry`, and the window's **Load set-aside files** workflow for subsequent passes.
- Optional Claude request compilation, exception advice, and opt-in generated formatting operations.
- Bundled OOXML schemas and the surgical-edit skill documentation.

## Install

**Windows 10/11 (64-bit):** download `SpecSurgeon-0.3.0-Setup-x64.exe`, run setup, then open **Spec Surgeon** from the Start menu. This installer was added after the original Python-package release. It includes Python, Tk, the engine, Word integration, the Anthropic client, and example EditSpecs. No Python setup is needed. It installs for the current user, offers a desktop shortcut, and includes an uninstaller that leaves user documents and result folders in place. The installer is unsigned; Windows may display a publisher/SmartScreen prompt.

For other platforms or a Python-based installation, Python 3.10 or newer is required. Download the wheel attached to this release, then run:

```powershell
py -3 -m pip install .\spec_surgeon-0.3.0-py3-none-any.whl
spec-surgeon-gui
```

On Windows, to add Word rendering and natural-language requests:

```powershell
py -3 -m pip install ".\spec_surgeon-0.3.0-py3-none-any.whl[word,agent]"
```

The Python-package desktop window needs Tk, included in the standard Windows Python installer. Rendering needs Microsoft Word (with the `word` extra for Python installations), or a separate LibreOffice installation. Word and LibreOffice are not bundled in the setup EXE. Natural-language requests need an Anthropic API key; loading a saved EditSpec does not. The standalone install includes example EditSpecs under the Start menu's **Example edit specs** shortcut.

The release also includes a source archive and `SHA256SUMS` for checking the downloaded distributions.

## Validation and limits

The original package release passed all 178 tests on Python 3.12/Linux with a virtual display and LibreOffice, distribution metadata checks, and a clean wheel installation with CLI smoke checks. The Windows installer is built on a native Windows x64 runner after the Windows suite passes. Validation installs the setup EXE, removes Python from PATH, runs the installed CLI and real GUI Preview → Run flow with parallel batch workers, exercises an isolated generated operation, checks bundled schemas/skill/client modules, and tests reinstall and uninstall.

This is a prototype release. Microsoft Word COM rendering and live Claude API calls remain unproven. The GUI has no cancellation button or saved session settings. Generated operations are formatting-only, opt-in, and their sandbox is not a security boundary. See the README for the detailed limits of each operation and verification check.
